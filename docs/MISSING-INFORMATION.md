## 产品内容复核

1. A75M：画册 p23 标为哑光型号，但光泽度与 A75 高光数据重复。已保留型号、7.5 mil 和 5 年画册期限；光泽度不对外发布，等待技术确认。
2. T 原色陶瓷 30590：窗膜 p9 的型号按原样保留，未擅自改为 0590 或其他型号。请确认是否为印刷错误。
3. TPU 英文颜色名为描述性翻译，尤其“中金星空粉”“星空尊崇幻红”“流光黑魅红”，需品牌确认官方出口名称。
4. “TPU 常规系列”是画册中的集合条目，不代表某一个具体颜色或独立 SKU。现以 Standard Collection 展示，需进一步色卡和 SKU 表。
5. 11 个 TPU 条目没有各自准确色板图片。当前使用标明用途的集合效果图，不把白车照片当作某个颜色实拍。请补充准确色卡、光泽/纹理照片。
6. PPF 表格的剥离力、环形初粘等数值缺少完整单位或测试条件，未把裸数值包装为正式规格。光泽度/接触角的双值含义也需确认。原始页保留供对照。
7. 层结构示意图中的厚度与总厚度可能采用不同测量口径，本次不自行换算或合计。请提供统一技术数据表。
8. 窗膜的 VLT、内反、UV、IR、TSER 均逐型号保留，未将 IR 与 TSER 混为同一指标。需要测试标准、光谱区间、测试报告及玻璃组合条件。
9. 画册质保期限不是已确认的海外服务政策。需海外覆盖地区、安装商要求、排除条款、登记流程和申请方式。
10. TPU p31 写有 5 年条件质保、自然褪色 3 年、授权店施工/电子质保条件，详情已注明；需要出口适用确认。
11. 原画册存在品牌历史表述差异；网站没有发布成立年份、国际公司背景、工厂产能、独立认证或测试结论。
12. 安装与养护文本仅转述画册，不能替代当地安装商针对材料、玻璃、漆面和环境的具体指导。

## 补齐后的验证入口

- 收件服务：在 `src/data/site.json` 填入真实 HTTPS JSON endpoint，重新执行 `npm run build`、`npm run check`，再用真实测试收件地址验证服务端校验、限流、垃圾提交和投递日志；不能只依赖浏览器拦截模拟。
- 联系方式与域名：确认公开邮箱/WhatsApp、域名和托管授权后更新 `site.json`，重新构建并在真实主机验证 DNS、TLS、根路径、404、缓存和 sitemap/canonical。
- 素材授权：取得品牌标识、车辆照片、膜材图和裁切图的海外公开商用许可凭证，逐项回填来源记录；没有凭证时保留当前阻塞状态或替换为已授权素材。
- 产品事实：由品牌/技术负责人确认 A75M 光泽、T 30590、TPU 官方英文名称/色板、测试条件、海外质保和可售型号，再更新 `src/data/catalog.mjs` 并重新跑全套检查。
- 实机与无障碍：在目标 iOS/Android 和辅助设备上人工复测导航、表单、焦点、错误提示、图片替代文字和横向布局，将结果追加到 `docs/QA.md`。
